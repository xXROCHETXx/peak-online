# Third-party components

- Original PEAK browser port: Dasher; upstream distribution at [wasmdotrip/Peak-Port](https://github.com/wasmdotrip/Peak-Port), pinned to `f1924c4fcd0099172f50f8d2a5273fda12fa1444`. PEAK is by Aggro Crab and Landfall. Original game data and level bundles are fetched from the upstream CDN.
- `experimental/photon-room.js` is a JavaScript adaptation of the protocol/room implementation in [Segually/photon-server](https://github.com/Segually/photon-server), revision `1e7cf407ad835a95d7e91e8a005bcc7df46732a4`, including local PEAK synchronization and voice-room fixes. It is provided as source under **GPL-3.0-only**. The full license is in [licenses/photon-server.txt](licenses/photon-server.txt). The browser implementation supports GpBinaryV18; it does not include the upstream UDP listener, plugin system, or application-layer encryption.
- [PeerJS 1.5.5](https://github.com/peers/peerjs/tree/v1.5.5) is loaded from jsDelivr under its MIT license. It handles WebRTC rendezvous and data-channel framing. The default PeerJS Cloud service is used for discovery. A host tab brokers game and voice packets for its own room; its lifetime ends when the host closes the tab.
- The local English name generator uses original curated word lists and the adjective-and-animal dictionary pattern demonstrated by [unique-names-generator](https://github.com/andreasonny83/unique-names-generator). It does not copy that package or call an external name service.
